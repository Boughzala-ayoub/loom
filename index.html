Overview

How statuses work

Waiting means an agent signaled for attention. Working follows terminal activity; quiet agents may still be thinking. Previewing a session keeps its waiting alert. Opening its thread or sending input clears it.

Start a thread

Each thread is a branch of work with its own agents. Run as many as you like; they keep going while you look elsewhere.
